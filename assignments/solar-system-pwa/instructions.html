Instructions & Documentation

Solar System Explorer PWA

User Instructions

  1. Open the Solar System Explorer app.
  2. Select a topic from the dropdown menu.
  3. Read the topic description and view the image.
  4. Click “Read Aloud” to hear the topic spoken.
  5. Install the app if the browser shows the install option.

App Features

This app uses HTML5, CSS, JavaScript, JSON, a web app manifest, and a service worker. The menu is dynamically populated using the topics stored inside data.json.

Programmer Documentation

To add a new learning topic, open data.json and add a new object inside the topics array. 

{
  "title": "Saturn",
  "description": "Saturn is famous for its beautiful rings.",
  "image": "image_url_here"
}

After saving data.json, the app will automatically add the new topic to the dropdown menu.
