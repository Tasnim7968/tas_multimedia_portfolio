Solar System Explorer

A fun educational PWA for learning about planets and space.

About the App

Solar System Explorer is a Progressive Web App that teaches early learners about the Sun and planets using text, images, and speech.

App Features

  • Dynamically loaded topics from a JSON file
  • Educational text and images
  • Text-to-speech read aloud feature
  • Installable PWA experience
  • Offline support using a service worker

How to Install

Open the app in Chrome or Edge. If the install option appears, click the Install App button or use the browser install icon near the address bar.
